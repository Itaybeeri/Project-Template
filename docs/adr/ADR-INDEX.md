# Architecture Decision Records (ADRs) — Index

The **global, append-only** record of architectural decisions and why we made
them — the trail of how our thinking evolved. ADRs live here, never inside
feature folders, because decisions outlive features and cross-cut them.

**Before writing or superseding any ADR, read [`ADR-RULES.md`](./ADR-RULES.md)** —
it holds the full, mandatory rules. Start a new ADR from [`ADR-TEMPLATE.md`](./ADR-TEMPLATE.md).
